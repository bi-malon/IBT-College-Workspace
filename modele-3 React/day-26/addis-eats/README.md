# Addis Eats - Static Menu (React + Vite)

This is a static menu application built for Module 3 - Day 26 using React and Vite. It demonstrates component composition, JSX syntax, and rendering lists using `.map()` with unique keys.

## Features

- **Header Component:** Displays the app title and subtitle.
- **Dish Component:** Reusable card receiving `name` and `price` via props.
- **Dynamic List Rendering:** Renders menu items from an array using `map()`.

## How to Run

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
