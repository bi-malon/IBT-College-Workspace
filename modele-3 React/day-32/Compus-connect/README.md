# CampusConnect — Student Community Portal

**Live Demo:** [https://ibtcompus.netlify.app/](https://ibtcompus.netlify.app/)

CampusConnect is a central web application designed for students across Full-Stack Web Development, Quality Assurance, and Cybersecurity tracks at IBT College, Qiyas, and EDI. It solves the challenge of scattered Telegram chat messages by organizing crucial academic announcements, module exam schedules, virtual class times, and townhall notices into clear, searchable cards.

## ✨ Features

- **Real Student Announcements:** Displays realistic, humanized announcement cards modeled directly after official IBT/Qiyas/EDI updates.
- **Module Exam & Schedule Details:** Detailed breakdowns for Module 1 & 2 exams, exam room assignments (e.g., Hall 304, Library), and session timings.
- **Track & Guild Directory:** Dedicated section for Backend Development tracks, Cybersecurity review guilds, and QA workshops.
- **Interactive Search & Filtering:** Quick client-side search to locate specific events, rooms, or program notices.
- **Favorites System:** Save and bookmark important announcements for quick access.
- **Dark Mode Support:** Theme toggle for low-light browsing between classes.

## 🛠️ Tech Stack

- **Frontend Framework:** React.js
