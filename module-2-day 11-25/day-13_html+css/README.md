# Business Profile Card (Day 13)

A styled profile card for a local Addis Ababa merchant built using CSS variables, typography hierarchy, and box-model fundamentals.

## CSS Techniques Applied:

- **CSS Custom Properties (`:root`)**: Palette (`hsl()`) and spacing scale reused via `var()`.
- **Global Reset**: Explicit `box-sizing: border-box` applied to all elements.
- **Box Model**: Precise padding, borders, margin auto-alignment, and border-radius.
- **Pseudo-Elements**: Decorative accent badge created using `::before`.
- **States & Accessibility**: Interactive `:hover` state adjusting lightness and explicit `:focus-visible` ring.
